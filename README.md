## GTK Backend

| Distribution	    | Installation Command          |
| ----------------- | ----------------------------- |
| Fedora            | `dnf install gtk3-devel`      |
| Arch              | `pacman -S gtk3`              |
| Debian & Ubuntu   | `apt install libgtk-3-dev`    |

[Source](https://docs.rs/rfd/0.15.4/rfd/#gtk-backend)
